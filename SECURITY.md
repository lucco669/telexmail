# Reporting a security problem

Please report security issues privately to **admin@telexmail.app**. Include the Telex version,
operating system, reproduction steps, expected impact, and a small example using a test mailbox.
Remove passwords, tokens and personal mail from attachments and logs. Do not publish exploit
details in a public issue before the report has been reviewed.

Reproduce against the latest published preview or the main branch when possible, and say which
one you tested. Telex is still a 0.x preview; this policy does not promise support for older versions
or a response deadline.

The website's [Privacy & security page](https://telexmail.app/security) explains protections and
current limits. [docs/security.md](docs/security.md) describes the automated checks and how to
repeat them. A completed automated check is evidence about its tested source and scope; it is
not an independent audit or a guarantee that an installer is harmless.
