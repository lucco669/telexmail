# Contributing

Telex is not open source: the code is public to read and review, but all rights are reserved
(see [LICENSE](LICENSE)). For that reason pull requests with code can't be accepted.

What helps a lot:

- **Bug reports and ideas** in [Issues](https://github.com/lucco669/telexmail/issues): the Telex
  version, Windows or Linux, what you did, what you expected and what happened. Leave out
  passwords and personal mail.
- **Security problems** go privately to admin@telexmail.app, as [SECURITY.md](SECURITY.md)
  describes, never in a public issue.
- **Translations and wording**: suggest them in an issue; they are written into the app by hand.
