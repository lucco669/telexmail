Telex

A check downloads one small file from GitHub that names the newest version. It sends nothing about you, your mail or this copy of Telex. An update installs only when you choose, and only if it carries Telex’s signature.

Identities

Who your mail is from. Each identity has its own signature and reply and forward headers. A reply is from the identity the message was sent to.

New identity

In the headers, these are filled in from the original message: {name} {email} {from} {date} {time} {subject}.

Rules

Rules run top to bottom on new mail as it arrives in an Inbox. A message a rule changes says so above its text.

Setting up

    Server settings

    Telex connects over SSL/TLS and checks both servers before saving. Reading, flagging, moving and deleting here does the same on the server. The first check downloads the newest 300 messages of each folder. Your password is kept in Windows Credential Manager and used for sending too.
