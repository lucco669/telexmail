Setting up

    Server settings

    Telex connects only encrypted (SSL/TLS or STLS) and checks both servers before saving. A POP3 server keeps only the Inbox: your folders are here, and reading, flagging and moving change nothing there. The first check downloads the newest 300 messages; older ones come on request. Back up this mail now and then: Settings › Backups.

    Telex connects only encrypted (SSL/TLS or STARTTLS) and checks both servers before saving. Reading, flagging, moving and deleting here does the same on the server. The first check downloads the newest 300 messages of each folder; older ones come on request. Your password is kept in the system’s password store and used for sending too.

    Identities

    Who your mail is from. Each identity has its own signature and reply and forward headers. A reply is from the identity the message was sent to.

    Folders

    Which of the server’s folders Telex uses for each kind of mail. Telex finds them itself and prefers the one that holds mail; choose another where it got it wrong. Your choice stays.

    Auto-reply

    Without days it starts now and goes on until you turn it off. Mailing lists, newsletters, robots and Spam never get it.

    New identity

    Signature

    In the templates and headers, these are filled in from the original message: {name} {first} {email} {from} {date} {time} {subject}. A new message has only {date} and {time}, today’s.

    New mail

    At once: Telex keeps a connection open to each Inbox (IMAP IDLE). Other folders are checked as often as set above.

    Spam filter

    It learns on this PC from your mail: what is in Spam is spam, mail you have read is not. Mail from people you have written to is never moved. Mark as spam and Not spam in a message’s menu teach it.

    Where Telex shows

    The system tray isn’t available here. On GNOME it needs the AppIndicator extension.

    Windows puts new icons behind the ^ arrow. To keep Telex’s icon always visible, turn it on in Windows’ taskbar settings, under Other system tray icons.

    The window

    In the tray Telex keeps checking and sending mail and notifies you of new mail. Quit it from the icon’s menu.

    Start when I sign in

    Telex is turned off in Task Manager’s Startup apps, so Windows doesn’t start it. Turn it on there.

    Mark messages as read

    By hand: U, the dot at the start of a row, or the envelope above a message.

    HTML mail

    H switches between them.

    HTML mail in a dark theme

    The sun button above a message shows it on white.

    Threads and warnings

    Threads: one row per conversation; → opens it, ← closes it. Scam warnings: a line above the message names the signs, such as a sender or link that imitates a known brand. Both are worked out on this PC.

    Remote images

    Images from the internet stay blocked until you load them, so senders can’t see when you open their mail. These senders’ images load without asking, except in Spam:

    Tags

    Keys 1 to 5 put the first five tags on the selected messages, or take them off. A message’s menu and the tag button above it have every tag.

    On the server a tag is a keyword, so Thunderbird and other programs show it too. Thunderbird’s five tags are these first five. Deleting a tag takes it off every message, here and on the server.

    New messages

    HTML always goes out with a plain-text copy. The switch above a message changes it for that one.

    Replies and forwards
    Signatures

    Saved as you type, with its formatting and a picture if you like; plain-text messages get its text. Greetings and reply and forward headers are with each identity: Edit identity.

    Folder templates

    A folder’s own greeting for new messages written while it is open and for replies to mail in it, and its own reply header. What is left empty comes from the identity. Also from a folder’s menu: Templates…

    Pictures

    Pictures pasted, dropped or inserted into an HTML message are made this size. A photo made smaller also loses its hidden details, such as where it was taken.

    Spelling

    Click an underlined word for suggestions; F7 goes to the next one. A word any ticked language knows is right, so one message can mix them.

    Sending

    Sent mail waits this long in the Outbox. Z takes it back to change it.

    Check for updates

    A check fetches one small file from GitHub that names the newest version, and sends nothing about you. An update installs only when you choose, and only with Telex’s signature.

    This build of Telex can’t update itself. Release builds from telexmail.app can.

    Counting

    Telex sends telexmail.app its version, the system, the interface’s language and the month it was first counted. No ID, no address, nothing about your mail: the site adds copies up and can’t tell them apart.

    Rules

    Rules run top to bottom on new mail as it arrives in an Inbox, and on a schedule where they have one. A message a rule changes says so above its text.

    New rule

    A pattern is a regular expression on the text in lowercase without diacritics (ł is l, ą is a), so case doesn’t matter. It is found anywhere unless ^ or $ hold it to the start or end: ^re: · faktur[ay] · fv/\d+

    Then

    When

    On a schedule the rule runs on these folders, never answers or forwards mail, and catches up once after Telex was closed.
